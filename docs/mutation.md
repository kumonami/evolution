При появлении популяции в регионе она содержит сущность Мутации. 
Мутация это слепок всех характеристик существа популяции. 
Мутация происходит случайно при рождении новой особи с вероятностью 0.1%
Мутация затрагивает случайным образом выбранные характеристики родителей новой особи.
Мутация может быть вредной или полезной. Изначально не понятно, какая мутация.
Если мутация позволила увеличить количество потомства существа с мутацией, 
то есть повысила выживаемость существа - это полезная мутация. Она с большим успехом получит развитие.
Если существо с мутацией не дало потомство, или дало мало потомства, то мутация получит меньшее развитие 
и быстрее исчезнет. 
Миграция не дает вероятности полезной мутации для нового биома. 
Изначально у популяции нет преимуществ для жизни в определенном биоме. 
Изначально существует только общий предок у всех популяций. 
Новые особи популяции общего предка получают мутации при каждом рождении.
Эти мутации могут быть незначительными.
Случайным образом популяция делится по миру, распространяется.  
Благодаря полезным мутациям создаются новые виды от общего предка. Поскольку вредные мутации не дают 
преимущества в распространении особей с мутацией, выживают и распространяются лучше те, кто имеет полезные мутации.
